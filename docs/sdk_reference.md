# CausalNerve Public SDK Reference

**Version:** 1.0.0 (API Frozen)

This document is the authoritative specification for the CausalNerve framework's core reasoning engine, `CausalNerveInstance`. 

## Core Principles
1. **No Silent Failures**: All invalid nodes, indices, and non-numeric inputs immediately raise `ValueError` or `TypeError`.
2. **Type Safety**: All public methods enforce strict Python type annotations.
3. **Deterministic Math**: Every call maps to exactly one deterministic structural equation or graph surgery operation.

---

## Initialization

### `CausalNerve.from_preset(domain_name: str) -> CausalNerveInstance`
Automatically looks up and compiles a domain plugin (e.g., `'aerospace'`, `'eeg'`) from the `PluginRegistry` and initializes the engine.

---

## 1. Streaming & Adaptation

### `fit(history: np.ndarray) -> None`
Fits the causal graph edge weights to historical baseline data.
- **Parameters:**
  - `history` *(np.ndarray)*: Shape (T, N) where T is time steps, N is node count.
- **Mathematical Note:** Computes structural edge strengths based on Pearson correlation matrices, masked by the domain's structural priors.

### `watch(telemetry: np.ndarray, on_alarm: Optional[Callable] = None, on_revision: Optional[Callable] = None) -> WatchCycleResult`
Processes one streaming telemetry step. Identifies anomalies (alarms) and proposes online causal graph revisions (OCGR).
- **Parameters:**
  - `telemetry`: (N,) sensor array for the current time step.
  - `on_alarm`: Callback executed if `leakage > threshold`.
  - `on_revision`: Callback executed if the Lyapunov gate proposes a structural graph edit.
- **Returns:** A `WatchCycleResult` dataclass containing the updated cycle, leakage score, and triggered events.

### `step(telemetry: np.ndarray) -> WatchCycleResult`
A streamlined alias for `watch()` designed for simple loop environments where callbacks are not required.

---

## 2. Structural Reasoning & Surgery

### `why(node: Union[int, str]) -> Dict[str, Any]`
Performs a weighted backward depth-first search to find the root cause of anomalous node behavior.
- **Returns:** Explanation dictionaries with `ranked_chains`, `confidence`, and `contribution_percentages`.

### `what_if(node: Union[int, str], value: float) -> Dict[str, Any]`
Executes a targeted, simulated dual-world counterfactual rollout to determine the effect of a specific value clamp on a single node without mutating the actual engine state.

### `rollout(intervention: Dict[Union[int, str], float]) -> Dict[str, Any]`
*(Replaces the deprecated `run_counterfactual()`)*. Executes a 50-step structural dual-world simulation applying interventions to *multiple* nodes simultaneously. 
- **Returns:** Full `divergence` tracking and trajectory separation metrics.

### `do(node: Union[int, str], value: float) -> Dict[str, Any]`
Pearl's `do(X=x)` calculus operation. 
1. **Severs** incoming edges to `node`.
2. **Clamps** `node` to `value`.
3. **Propagates** the effect instantly to descendants.
4. **Mutates** the internal engine state vector.

---

## 3. Fleet & Epidemiology

### `predict_next_change() -> Dict[str, Any]`
Reads the graph revision history generated by `watch()` and performs frequency-weighted recurrence analysis.
- **Returns:** A prediction on which edge is statistically most likely to fail or be removed next, alongside confidence bounding.

---

## 4. Reporting & Visualization

### `export_report(filepath: str) -> None`
Exports the live graph state, active node states, and complete OCGR revision history to a JSON file.

### `plot_graph(filepath: str = "graph.png") -> None`
Generates an `.svg` visual render of the current graph topology, highlighting node states and edge strengths.

---

## Deprecations
* `run_counterfactual()` -> **Deprecated in 1.0.0.** Use `rollout()` instead. Triggers a `DeprecationWarning` and will be permanently removed in `2.0.0`.
